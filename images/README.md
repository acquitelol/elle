## ✩ How was this made?

> [!IMPORTANT]
> Elle's design is constantly changing. At the moment, Elle's mascot is a pastel pink butterfly called **Mia**.

I found a really pretty butterfly made out of wires at the [Eden Project, Cornwall](https://www.edenproject.com/), and I thought it would look great as an icon/mascot for Elle, so I took a picture of it and used it as a reference for the current icon! ₊˚ ♡︎
